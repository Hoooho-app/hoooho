# 产品定位

Hoooho 是一款就诊前准备工具。

它位于用户和正式医疗服务之间，作用类似医院里的导诊台或护士站，但使用场景发生在用户去医院之前。

## 核心定位

帮助用户把零散的健康信息整理成医生容易理解的内容。

## 核心功能

### 科室初步分诊

根据用户描述的主要问题，帮助用户初步判断更适合前往哪个科室。

### 病情整理

通过结构化提问，帮助用户梳理症状、时间、变化、影响和相关信息。

### 问诊摘要

把整理后的信息生成简洁摘要，供用户在就诊时查看或向医生展示。

## 使用场景

Hoooho 主要用于：

- 在家准备看病信息
- 去医院之前整理症状
- 挂号前初步了解科室
- 就诊时快速向医生说明情况
